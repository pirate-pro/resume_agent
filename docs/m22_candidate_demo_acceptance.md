# M22 候选版人工演示验收

## 目标

M22 不新增主功能。目标是按 M21 运行手册完整走一遍候选版演示路径，确认当前版本可以作为候选版基线。

本阶段只做三类事情：

```text
1. 按真实用户路径人工演示。
2. 记录 P0 / P1 / P2 问题。
3. 只修阻断候选版试用的问题。
```

不做：

- 新服务。
- 新工具。
- 新 Agent 能力。
- RAG / MCP。
- memory 自动写入。
- 提醒系统。
- 外部知识库写入。
- 大并发压力测试。

## 前置条件

已完成：

- M21 自动化回归。
- M21 低批次真实 smoke。
- M21 工作台关键交互测试。
- M21 候选版运行手册。

参考文档：

```text
docs/m21_candidate_runbook.md
docs/m21_product_acceptance_report.md
```

## 人工演示路径

演示路径按 M21 运行手册执行：

```text
1. 启动后端和前端。
2. 新建会话。
3. 上传测试简历。
4. 诊断简历并生成画像。
5. 粘贴 JD 并生成 JD 分析、匹配报告和求职项目。
6. 生成定制简历。
7. 打开工作台查看项目、资料和报告。
8. 保存一条学习类笔记。
9. 只生成准备建议。
10. 确认加入学习任务。
11. 用户主动添加一个学习任务。
12. 记录一次学习进度并更新任务状态。
13. 回到工作台确认资产、笔记、任务和时间线可见。
```

## 验收检查表

### 1. 启动与首页

通过标准：

- 后端 `/health` 正常。
- 前端首页不是空白页。
- 新建会话可用。
- 上传入口、输入框、工作台入口可见。

阻断问题：

- 页面空白且重启无法恢复。
- 后端不可用。
- 上传或发送入口不可用。

### 2. Agent 执行体验

通过标准：

- 用户发送任务后能看到进度。
- 工具调用和 Agent 执行不会让用户误以为卡死。
- 完成后有明确结果说明。

阻断问题：

- 长时间无任何进度反馈。
- 主任务失败后无可理解错误。
- 同一任务重复触发导致资产明显混乱。

### 3. 求职资产链路

通过标准：

- 简历画像、职业画像、JD 分析、匹配报告、定制简历都能落库。
- 用户可见 Markdown 结果能预览。
- 求职项目能串起简历、JD、报告和定制简历。

阻断问题：

- artifact 无法预览。
- 求职项目缺失关键关联。
- 报告内容明显未渲染或不可读。

### 4. 工作台体验

通过标准：

- 项目页能看懂当前目标岗位和匹配结论。
- 资料与报告页能找到诊断、JD、匹配报告和定制简历。
- 笔记页能创建、编辑和 Markdown 预览。
- 学习页能查看任务、添加任务和打卡。

阻断问题：

- 工作台入口不可见。
- 工作台数据刷新后仍看不到刚生成的资产。
- 核心弹层打不开或无法关闭。

### 5. 产品边界

通过标准：

- 只问建议时不创建学习任务。
- 确认加入任务后才创建 LearningTask。
- 保存笔记只写 Note。
- 默认不写 memory。
- 不重复解析简历或重复分析 JD。

阻断问题：

- Agent 越界写 memory。
- Agent 把笔记、学习任务、求职项目混写。
- 创建记录缺少 source 或 evidence，导致无法追溯。

## 问题分级

### P0

必须立即修：

- 应用无法启动。
- 页面空白且重启无效。
- 主链路无法完成。
- 产品记录损坏或无法读取。
- 用户可见文件无法预览。
- Agent 明确越界写 memory。

### P1

候选版前优先修：

- 关键入口找不到。
- 报告或工作台核心区域明显不可读。
- 资产重复展示导致用户无法判断最新版本。
- 学习任务、笔记或项目之间跳转断裂。
- 真实演示中多次出现可恢复但严重拖慢体验的问题。

### P2

记录到后续优化：

- 局部视觉不够精致。
- 移动端轻微拥挤。
- 个别按钮文案还可以更自然。
- 单 run 耗时偏长但进度可见。
- 调试信息后续正式版再隐藏。
